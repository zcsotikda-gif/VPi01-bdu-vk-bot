# Экраны и сценарий продаж

- Маршрут — по `payload.action` кнопки; текст кнопки только запасной путь.
  Новый action = функция `(ctx, user, payload) -> Reply | list[Reply]` + запись
  в `ACTIONS` в `router.py`.
- JSON клавиатур собирается только в `keyboards.py`; handlers отдают spec.
- На каждом ключевом экране есть «Главное меню»; из глубокой ветки — «Назад».
- Не больше 4–5 основных кнопок на экран.
- Квалификация: один вопрос — одно сообщение.
- Sales flow не обязателен: свободный текст в любом состоянии уходит в LLM
  (кроме шагов квалификации, контакта и подтверждения).
- Услуги, цены, сроки — только через `CatalogService` из `services.json`;
  пустую цену или срок не показывать и не придумывать.
- Тексты для человека — в `texts.json` (согласие меняется после юридической
  проверки без правки кода).
- Повторное нажатие не создаёт второй lead или handoff и не шлёт второе
  уведомление менеджеру; `ADMIN_VK_ID` не попадает в сообщения пользователю.
- Контакт сохраняется только при `consent_pd = 1`.
