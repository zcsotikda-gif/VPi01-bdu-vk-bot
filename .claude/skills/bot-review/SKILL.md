# Ревью vk-bot перед завершением

Порядок: тесты зелёные (хук Stop их и так требует) → три ревью → существенные
замечания исправить с тестом → отчёт. Каждое замечание — с файлом и строкой;
«нет замечаний» — тоже с тем, что проверено.

## 1. Senior Python
- Лишняя сложность: новые слои, ORM, DI, абстракции без второго пользователя.
- Дублирование: одинаковые клавиатуры/тексты/запросы в двух местах.
- Разделение: VK — только `services/vk_service.py` и `__main__.py`; SQL — только
  `storage/repository.py`; LLM — только `services/llm_service.py` и `llm_client.py`;
  handlers не знают про VK и SQL. Проверка: `grep -rn "import sqlite3\|vkbottle" src/vk_bot/handlers`.
- Ошибки: широкий `except` только на границе и с причиной; сбой не роняет Long Poll.
- Глубже по границам — скилл `clean-architecture-review`.

## 2. Sales / UX
- Первое полезное предложение — не позже 2–3 действий от приветствия.
- Понятно, что продаётся: карточка — для кого, что решаем, что получаете.
- Вопросов квалификации 3, по одному на сообщение.
- На каждом экране есть следующий шаг (CTA) и «Главное меню»; менеджер
  доступен из меню, после LLM-ответа и во время квалификации.
- Не больше 4–5 основных кнопок.

## 3. Security / QA
- Токены: `grep -rnE "vk1\.a\.|sk-[A-Za-z0-9]{10,}" src tests` → пусто; `.env` в `.gitignore` и `.dockerignore`.
- Контакты в LLM: всё, что уходит в `llm.answer`, проходит `redact()`.
- Двойная заявка: повтор события и повторное нажатие не создают второй lead/handoff.
- Restart: состояние читается из SQLite (тест `test_state_survives_restart`).
- Malformed: битый payload, неизвестный action, неизвестное состояние, пустой текст.
- Одна копия бота: `instance_lock` в `__main__.py` на месте.

## Критерии готовности (из задания)
Бот запускается · персональное приветствие · рабочая клавиатура · команды ·
ветки person/business · каталог · свободный вопрос LLM · LLM не управляет state ·
квалификация · данные переживают restart · lead в SQLite · менеджер получает
уведомление · отказ в согласии · ошибка LLM не ломает бота · повтор события не
даёт второй lead · секретов нет в репозитории · тесты зелёные · README
позволяет запустить с чистого окружения.

Пункты, которые проверяются только вживую (уведомление менеджеру, клавиатура
в клиенте VK), — через скилл `bot-live`; без живого прогона так и написать в
отчёте: «не проверено вживую».
